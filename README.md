# Nomie Apple Watch v2

Syncs the trackables you choose to the Apple Watch app, through the Apple Watch API server. The calls to the server are unchanged from v1.

Source: https://github.com/RdeLange/nomie-applewatch-v2. Pages: https://dailynomie.github.io/nomie-applewatch-v2/

## Commands

    npm install
    npm test
    npm run build
